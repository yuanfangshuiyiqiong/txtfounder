# 向量数据库搜索系统 - 操作手册

欢迎使用文件搜索系统。本手册将引导您如何高效地使用本系统进行文档检索和管理。

## 1. 系统简介
本系统是一个基于人工智能的智能文档检索工具。它不仅能通过关键词进行搜索，还能理解您输入内容的含义，为您找到语义最相关的文档片段。

## 2. 核心功能说明

### 2.1 智能搜索
- **如何搜索**：在页面中心的搜索框中输入您想要查询的问题或关键词（例如：“如何请假？”或“报销流程”），然后点击“搜索”按钮或按下回车键。
- **搜索结果**：系统会列出与您的查询最相关的文档内容。
    - **相似度**：百分比越高，表示该内容与您的查询意图越匹配。
    - **来源路径**：显示该内容出自哪一个具体文件。

### 2.2 结果数量调节
- 您可以通过搜索框下方的滑动条来调整返回结果的数量（默认为5条）。如果您希望获取更多参考内容，可以将滑动条向右拖动。

### 2.3 索引更新管理
为了保证搜索结果的准确性，当您在文档目录中新增或修改了文件后，需要手动更新系统索引：
- **增量更新**：仅扫描并添加新文件或修改过的文件。建议在日常添加少量文件后使用。
- **重新构建**：清空旧索引并重新扫描所有文件。建议在文件发生大规模变动或系统出现异常时使用。

## 3. 常见问题
- **搜索不到结果？** 请检查搜索词是否过于简略，或确认相关文件已放入指定的 `data` 目录并点击了“增量更新”。
- **显示内容不全？** 搜索结果仅展示最相关的片段，如需查看全文，请根据显示的“路径”找到原始文件。
